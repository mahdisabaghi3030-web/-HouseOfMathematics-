# خانه ریاضیات — راهنمای کامل راه‌اندازی (رایگان)

این پوشه اسکلت کامل سایت «خانه ریاضیات» است: صفحه اصلی، ثبت‌نام/ورود، آزمون‌های
تستی و تشریحیِ زمان‌دار، بخش آموزش، بخش کتاب‌ها (پیگیری صفحه و سوال)، بخش
دوره‌ها، و بخش رقابت/رتبه‌بندی. فعلاً داده‌ها نمونه (mock) هستند تا وقتی
دیتابیس واقعی وصل شود.

هیچ‌کدام از مراحل زیر پولی نیست. سه سرویس رایگان استفاده می‌کنیم:

| سرویس | کاربرد |
|---|---|
| **GitHub** | نگهداری کدها |
| **Supabase** | دیتابیس + سیستم ثبت‌نام/ورود کاربران |
| **Vercel** | آنلاین کردن سایت (هاستینگ) |

---

## مرحله ۱ — بالا بردن کد روی گیت‌هاب

1. وارد github.com شو و اکانت بساز (اگر نداری).
2. یک ریپازیتوری جدید بساز، مثلاً به نام `khaneh-riazi` (خصوصی یا عمومی، فرقی نمی‌کند).
3. تمام فایل‌های این پوشه را در آن ریپازیتوری آپلود کن. ساده‌ترین راه برای مبتدی:
   - در صفحه‌ی ریپازیتوری روی «Add file → Upload files» بزن و تمام پوشه را بکش و رها کن.
   - یا اگر Git نصب داری:
     ```bash
     cd khaneh-riazi
     git init
     git add .
     git commit -m "اسکلت اولیه خانه ریاضیات"
     git branch -M main
     git remote add origin https://github.com/USERNAME/khaneh-riazi.git
     git push -u origin main
     ```

## مرحله ۲ — ساخت دیتابیس در Supabase

1. به supabase.com برو و با ایمیل یا گیت‌هاب ثبت‌نام کن (رایگان).
2. «New Project» بزن، یک اسم و رمز عبور برای دیتابیس انتخاب کن (رمز را جایی یادداشت کن).
3. بعد از ساخته شدن پروژه، از منوی سمت چپ وارد **SQL Editor** شو.
4. محتوای فایل `supabase/schema.sql` (همین پوشه) را کامل کپی کن، در SQL Editor
   پیست کن و دکمه‌ی **Run** را بزن. این کار تمام جدول‌های مورد نیاز (کاربران،
   آزمون‌ها، سوالات، کتاب‌ها، مقالات، دوره‌ها و ...) را می‌سازد.
5. از منوی **Project Settings → API** دو مقدار زیر را کپی کن:
   - `Project URL`
   - `anon public` key

---

## مرحله ۳ — آنلاین کردن سایت با Vercel

1. به vercel.com برو و با اکانت گیت‌هابت وارد شو (رایگان).
2. «Add New → Project» بزن و ریپازیتوری `khaneh-riazi` را انتخاب کن.
3. در بخش **Environment Variables** این دو مقدار را که از Supabase گرفتی اضافه کن:

   | Name | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | همان Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | همان anon public key |

4. روی **Deploy** بزن. بعد از ۱-۲ دقیقه، یک لینک رایگان مثل
   `khaneh-riazi.vercel.app` بهت می‌دهد — این آدرس سایت توست، همین الان
   آنلاینه و هر کسی می‌تونه ببینتش.

> هر بار که کد را روی گیت‌هاب آپدیت کنی، Vercel خودکار دوباره دیپلوی می‌کند.

### دامنه‌ی اختصاصی (اختیاری)
اگه بعداً خواستی مثلاً `khanehriazi.ir` یا `.com` بخری، از داخل تنظیمات
پروژه در Vercel، بخش **Domains**، می‌تونی دامنه‌ی خریداری‌شده را وصل کنی.
خود دامنه رایگان نیست (چون ثبت دامنه هزینه دارد)، ولی هاست کردنش روی Vercel
رایگانه.

## مرحله ۴ — اجرای محلی روی سیستم خودت (اختیاری، برای تست قبل از آپلود)

اگر Node.js نصب داری:

```bash
cd khaneh-riazi
cp .env.example .env.local
# مقادیر Supabase را داخل .env.local بگذار
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کن.

اگر Node.js نصب نداری، از nodejs.org نسخه‌ی LTS را دانلود و نصب کن.

```
  schema.sql               اسکیمای کامل دیتابیس
```

## چه کارهایی هنوز باقی مانده؟ (قدم بعدی)

هرکدام از این‌ها را که بگی، در پیام بعدی می‌سازم:

1. **اتصال واقعی صفحات به Supabase** — الان صفحات آزمون/کتاب/داشبورد از
   داده‌ی نمونه استفاده می‌کنند؛ باید به `fetch` واقعی از دیتابیس وصل شوند.
2. **تصحیح خودکار آزمون تستی** و محاسبه‌ی امتیاز و به‌روزرسانی سطح کاربر.
3. **پنل ادمین** برای اینکه خودت بتونی از داخل سایت سوال/کتاب/مقاله اضافه
   کنی (بدون نیاز به SQL دستی).
4. وقتی منابع (سوالات، کتاب‌ها، مقالات، لینک دوره‌ها) را برایم بفرستی، آن‌ها
   را داخل دیتابیس/کد قرار می‌دهم.

فقط بگو کدوم بخش رو ادامه بدم.
